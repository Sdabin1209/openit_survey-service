# ADR-0044: 문진 스키마 2.0.0: SessionResult.skipped 폐지, skipped_details만 (정수 CONTRACT_VERSION은 그대로)

## 상태
승인(헤드 브리프 계약 3.0.0 전환, ADR-0036의 2.0.0 후보 실행). 문진 스키마 태그는 헤드가 만든다.

## 결정
`SessionResult`에서 문자열 목록 `skipped`를 지우고(`skipped_details`가 필수 필드) 패키지 버전을 2.0.0으로 올렸다(깨지는 변경: 결과를 읽는 병원 시스템이 `skipped_details`로 옮겨야 한다). 세션 문서의 `progress_record.skipped`(내부 진행 기록)는 그대로다.
**정수 `CONTRACT_VERSION`은 1 그대로 둔다.** 이 번호는 런타임 호환 번호(문항 은행·칸 키를 학습한 모델 패키지, 릴리스의 `runtime_contract_version`)이고 `SessionResult`는 모델이 보지 않는 출력 형식이라 올리면 모든 릴리스·모델 패키지가 호환되지 않게 된다. 그래서 패키지 MAJOR와 정수 버전이 같다는 이전 시험 규칙(D110)을 "패키지 MAJOR가 정수 버전보다 뒤처지지 않는다"로 고쳤다. 정수 번호도 올려야 한다고 헤드가 판단하면 전 영역 이행이 필요하다(질문으로 남긴다).

## 왜
ADR-0036이 `skipped` 폐지를 2.0.0 후보로 적었고, 3.0.0 계약 전환에 맞춰 낸다.

## 결과
얻는 것: 빈칸 원인이 한 필드(코드)로만 나간다. 감수하는 것: 결과를 읽는 쪽이 `skipped`를 읽고 있었다면 깨진다(병원 시스템에 아직 운영 데이터 없음, 계약 3.0.0 CHANGELOG 기준).
