# 계약 4의 기기 인증과 서버 발급 세션 ID

## 상태
채택 (2026-11-08).

## 결정
공개 키오스크 인증은 게이트웨이의 mTLS가 담당한다. 서비스는 게이트웨이와 공유하는 SURVEY_API_TOKEN_ENV의 비밀을 검증하고, 그 요청의 X-Openit-Device로 세션 소유권을 확인한다. 서비스의 기기별 토큰 표와 설정은 제거한다. 입력 선언은 SURVEY_API_TOKEN_FILE을 포함한다.

공개 시작 본문은 SessionStartBody로 검증하고 session_id를 거부한다. 서버는 CSPRNG로 ID를 발급해 내부 메시지와 Trace에 넣고 응답한다. SESSION_START는 멱등이 아니며 turn_id는 새 세션의 첫 턴 ID다. 내부 FrontendMessage의 session_id는 이 단계에 필요하므로 유지한다.

동적 module:function 환경 설정을 제거한다. 운영 의존은 계약의 HTTP 설정으로 연결하고, 시험 대역은 생성자 인자로 주입한다. 운영 진입점의 기본 배선과 시험 진입점의 대역 배선을 구분한다.

알림 스트림은 staff와 clinician의 계정 노출을 각각 선언한다. clinician은 survey-result-reader 상류 토큰으로 연결하며 이벤트는 인증된 역할 헤더로 제한한다. 구독 해지는 POST 경로만 제공한다.

## 검증과 영향
문진 스키마 사본 일치 검사, 공개 시작 본문의 클라이언트 ID 거부, 서버 발급 ID와 기기 소유권, 역할별 SSE 시험을 유지한다. 이미지 스모크는 서버 응답 ID를 다음 요청에 사용하고 실제 stdin CLI와 PostgreSQL 재시작 뒤 세션 유지를 확인한다.

최종 계약 조합과 전체 시험 결과는 docs/STATUS.md에 기록한다. 전체 프로젝트 E2E는 영역 검증과 별도로 실행한다.
