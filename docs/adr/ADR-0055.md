# ADR-0055: 운영 소요 시간 지표를 prometheus_client로 기록하고 내부망 GET /metrics로 낸다 (U71)

## 상태
승인(헤드 지시 U71, 2026-11-03). 버킷 값은 **측정하지 않았다**.

## 맥락
계약 3.2.0 METRICS.md "운영 소요 시간 지표"가 이 영역에 두 지표를 정했다: `openit_turn_duration_seconds{outcome=ok|failed|paused}`(목표 p95 ≤ 2.0초)와 `openit_model_call_duration_seconds{op=extract|respond, outcome=ok|invalid|timeout|unavailable}`(합 p95 ≤ 1.5초). 목표(SLO)는 실패 판정이 아니다(D125). 서비스에는 시간을 재서 내보내는 길이 없었다(`/readyz`의 호출 통계는 건수만 있다).

## 결정
- 의존: `prometheus_client==0.26.0`(PyPI, 잠금 파일에 고정). 지표 종류는 히스토그램(계약이 정함).
- 기록 지점: 턴은 `Orchestrator.handle_turn`(저장된 결과를 재생한 턴은 세지 않는다. 재생은 처리 시간이 아니다). 모델 호출은 추론 서버 클라이언트의 시도 하나가 끝날 때(`link_inference.Stats.record_call`의 관찰자 콜백, 재시도는 시도마다 센다). 프로세스 안 `load`(개발·스모크용 `InferenceServer`)는 세지 않는다.
- 결과 이름: 턴은 실패 신호가 없으면 `ok`, 직원 알림이 닿았거나 정지 사유가 있으면 `paused`, 그 밖의 신호는 `failed`. 모델 호출은 성공 `ok`, 출력 계약 위반 `invalid`, 읽기 시간 초과 `timeout`, 그 밖의 실패 `unavailable`.
- 내보내기: 내부망 `GET /metrics`(인증 없음, 텍스트 노출 형식). `deploy-exposure.json`에서 `denied`라 gateway로 나가지 않는다.
- 버킷: 턴 0.1~50초(목표 2.0, 상한 50 경계 포함), 모델 호출 0.05~26초(목표 1.5, 상한 21·26 경계 포함). 사이는 대략 두 배씩.
- 라벨에 세션 ID·발화·기기 ID 등 식별자를 넣지 않는다(결과 이름과 op뿐).

## 왜
- Prometheus 텍스트 노출 형식과 `prometheus_client`는 METRICS.md가 이름 관례(`_seconds`)로 가정한 표준 경로다. 직접 형식을 만들면 버킷·`_sum`·`_count` 규칙을 다시 구현하게 된다.
- 인증 없는 `/metrics`: Prometheus 스크레이프의 표준 형태이고, 노출은 네트워크 경계(gateway denied)로 막는다. `/healthz`·`/readyz`도 같은 방식으로 내부에서 인증 없이 답한다.
- 버킷 경계를 목표와 상한에 맞춘 이유: "목표 초과 비율"과 "상한에 닿은 비율"을 히스토그램의 누적 버킷에서 바로 읽는다. 실제 분포는 측정하지 않았다. GPU 실측 뒤 조정한다.
- 관찰자 콜백으로 기록하는 이유: 구조 규칙(컴포넌트는 서로 모른다): 추론 클라이언트 컴포넌트는 지표가 무엇인지 모르고 콜백만 부른다. 콜백이 실패해도 턴·호출은 실패하지 않는다.

## 검토한 대안과 버리는 이유
- `/readyz`에 지표를 섞기: 응답 총 마감 2초(ADR-0027)와 계약 `SurveyReadyz` 모양에 얽히고 Prometheus가 읽지 못한다.
- OpenTelemetry: 계약이 Prometheus 관례를 이름으로 정했고 수집기는 deploy가 정한다. 지금 필요한 것은 히스토그램 두 개다.
- 요청 단위 미들웨어로 턴 시간 재기: 공개 API의 사전 확인 시간까지 들어가고 직원 경로와 섞인다. 턴 처리 함수가 정확한 경계다(턴 총 마감도 같은 시작 시각을 쓴다).

## 결과
얻는 것: SLO 달성 여부를 지표로 본다. 감수하는 것: 의존 하나 추가; 프로세스별 지표라 서비스를 여러 프로세스로 나누면 합산은 수집기 몫이다(지금 배포는 한 프로세스, ADR-0004); 인증이 없으므로 네트워크 분리가 깨지면 지표가 보인다(내용은 건수·시간뿐이고 식별자 없음).

## 되돌리는 조건
계약이 지표 이름·라벨을 바꾸거나, 버킷이 측정과 크게 어긋날 때.
