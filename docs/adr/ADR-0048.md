# ADR-0048: 공개 API 받는 쪽을 openit_link.App 위로, 컴포넌트가 wiring을 import하지 않는다, 입력 검사는 wiring이

## 상태
승인(헤드 지시 U400 2차, 2026-10-30). ADR-0047의 한계 L1, L4, L5의 일부를 해소한다.

## 맥락
공개 API(`link_public_api`)가 토큰 -> 역할 401/403, 본문 상한, JSON 해석(중복 키·서로게이트·중첩), 라우팅을 직접 구현했고, 컴포넌트가 `wiring/errors`·`pg`·`netguard`를 import했으며, 컴포넌트 입력 검사는 컴포넌트 안의 손 검사였다.

## 결정
1. 받는 쪽은 `openit_link.App`(v0.3.0) 위로 옮긴다. 경로 표(`_SPEC`)가 `Route`를 만들고, 기기 머리글 인증은 `authenticate`, `Retry-After`는 `HttpError`, 엄격한 JSON·413·405는 라이브러리가 한다. `server.py`에는 서버 고유 겉옷(X-Request-Id, 204, SSE 스트림 연결)만 남는다.
2. 컴포넌트는 자기가 던지는 예외를 파일 안에 `BoundaryError` 하위 클래스로 정의하고 `details.reason`으로 구조적으로 알아본다(`STORE_ERROR` `STORE_EFFECT` `STAFF_CALL_REJECTED` `DELIVERY_FAILED` `INFERENCE_LOAD` `RELEASE_UNAVAILABLE` `TURN_INPUT`). wiring은 `wiring/errors.py`에서 같은 뜻의 클래스를 튜플로 묶고(`StoreError`), `link_public_api`는 `orchestrator.errors`(wiring이 건넨 이름표)로 잡는다.
3. `PgConn`은 `session_store`에 두고 `trace_outbox`·`alert_book`에는 생성자 인자(`connect`, `driver_errors`)로 주입한다. 주소 검사(SSRF)는 `link_push`로 옮기고 `AlertService.endpoint_error`(주입된 `endpoint_check`)로 노출한다. `LoadedRelease`는 `release_loader`에 둔다.
4. 컴포넌트 입력 검사는 `wiring/checked.py`가 `types.validate`로 한다. 오래 사는 문서(문항 세트·흐름·표)는 같은 객체를 한 번만 검증한다(문항 세트 한 번에 약 100ms, 측정).

## 왜
- 표준: DESIGN.md 4·5·6절, CONVENTIONS 6·9절(401/403, BoundaryError 본문), I-JSON(RFC 7493).
- 스키마로 검증하자 실제로 어긋난 입력이 드러났다: 합성 REASK(추출 연속 실패 승격)가 계약 `ActionExtraction`이 요구하는 `targets`를 빼고 있었다(코드 결함, 고쳤다). 시험의 문항 세트가 세 상한을 지워 QuestionBank 3.0.0 스키마를 어기고 있었다(시험 결함, 고쳤다).

## 검토한 대안과 버리는 이유
- 컴포넌트마다 예외 클래스를 새로 정의하고 wiring이 모두 안다: `except` 지점이 늘어난다. 튜플과 reason으로 최소화했다.
- 호출마다 문항 세트를 전부 검증: 턴마다 약 100ms 이상. 같은 객체 한 번으로 줄였다(측정은 문항 세트 검증 한 번 기준이고 턴 전체 지연은 측정하지 않았다).

## 결과
얻는 것: 401/403·본문 검사의 중복 구현이 없어지고 컴포넌트가 wiring을 모른다. 감수하는 것: 와이어가 달라진 곳(아래), 예외 클래스 복제(L2), 일부 컴포넌트의 입력 검사 미적용(L5 잔여: docs/components.md 4절).

와이어가 달라진 곳(허용된 변경): 본문 64KiB 초과 400 -> 413; 알려진 경로에 다른 메서드 404 -> 405 + Allow; 오류 응답 Content-Type에서 charset 빠짐, Cache-Control no-store, 401/403 문구; 판정 순서(413 -> 토큰 -> 사람 머리글 -> 본문 해석 400); GET·DELETE 본문도 JSON 해석; 쿼리 중복 키는 마지막 값; 경로 조각은 퍼센트 해제 뒤 검사; 공개 API 밖 알 수 없는 경로는 BoundaryError 본문의 404.

## 되돌리는 조건
link가 위 항목 중 하나를 바꾸거나 응답 형식 차이가 키오스크에서 문제가 되면 해당 경로만 겉옷에서 되돌린다.
