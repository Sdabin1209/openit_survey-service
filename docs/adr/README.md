# 설계 결정 기록 (ADR)

구조·기본값 선택마다 '왜'에 답하기 위한 기록이다(Nygard 형식: 상태, 맥락, 결정, 왜, 검토한 대안, 결과, 되돌리는 조건). 측정하지 않은 값은 '측정 안 함'으로, 근거를 찾지 못한 것은 '근거 기록 없음'으로 적었다. 코드의 상수·기본값 주석은 ADR 번호를 가리킨다.

- [ADR-0001](ADR-0001.md) 세션·outbox·알림 저장소의 개발·시험 기본으로 SQLite를 쓴다
- [ADR-0002](ADR-0002.md) 운영 저장소는 PostgreSQL(서비스별 DB·최소권한 계정)이다
- [ADR-0003](ADR-0003.md) psycopg3 직접 사용, ORM 없음, 연결 풀 없음
- [ADR-0004](ADR-0004.md) HTTP 서버는 표준 라이브러리 ThreadingHTTPServer이고 한계를 문서화한다
- [ADR-0005](ADR-0005.md) 한 턴의 오케스트레이션은 LangGraph StateGraph이다
- [ADR-0006](ADR-0006.md) 세션은 문서(JSON) 한 줄과 정수 revision으로 저장한다
- [ADR-0007](ADR-0007.md) 같은 turn_id는 멱등이고 세션 락으로 순서를 지킨다
- [ADR-0008](ADR-0008.md) 서버 턴 마감 6초와 timeout 체인
- [ADR-0009](ADR-0009.md) Trace는 영속 outbox를 거쳐 비동기로 보낸다 (outbox 쓰기 방식은 ADR-0023이 대체)
- [ADR-0010](ADR-0010.md) 직원 알림 스트림은 SSE이다(WebSocket 아님)
- [ADR-0011](ADR-0011.md) DB 접속·문장 timeout, 재접속 유예, 우아한 종료
- [ADR-0012](ADR-0012.md) 추출 입력(JSON) 길이를 2400자로 제한한다
- [ADR-0013](ADR-0013.md) 위험 규칙 감지는 모든 발화 턴에 모델·확정과 분리해 적용한다
- [ADR-0014](ADR-0014.md) 같은 질문 반복(REASK·CONFIRM) 상한은 기본 3, 문항 세트 저작값이 있으면 그 최솟값 (ADR-0020이 대체)
- [ADR-0015](ADR-0015.md) 보존 기본값은 유한하고 무기한은 거부한다
- [ADR-0016](ADR-0016.md) 키오스크 토큰은 기기별로 받고 세션은 만든 기기만 접근한다
- [ADR-0017](ADR-0017.md) 값 검증은 계층이다: 형식(계약) -> 의미(turn-engine) -> 값 타당성(서비스)
- [ADR-0018](ADR-0018.md) HTTP 계층 방어: 소켓 읽기 제한, 접속·SSE 상한, 웹 푸시 SSRF 차단
- [ADR-0019](ADR-0019.md) 장애 시험은 자기가 띄운 PostgreSQL 컨테이너만 이름으로 멈춘다
- [ADR-0020](ADR-0020.md) 연속 되묻기 상한 N=3, 4번째에 직원 호출 (ADR-0014 대체)
- [ADR-0021](ADR-0021.md) 직원 호출 재알림·실패 기록: 간격 30초·상한 10회(측정 안 함), 두 단계 기록 (CR-H001)
- [ADR-0022](ADR-0022.md) 정지 사유 pause_reason은 알림 행과 세션 문서에서 도출한다 (CR-H002)
- [ADR-0023](ADR-0023.md) Trace outbox 행을 세션 commit과 같은 DB 트랜잭션에 쓴다 (ADR-0009 일부 대체)
- [ADR-0024](ADR-0024.md) 역할 토큰의 최소 길이는 기기 토큰과 같은 16자이다 (D03)
- [ADR-0025](ADR-0025.md) 근거 없는 값의 출처 분류(점검 N-, 값은 바꾸지 않음)
- [ADR-0026](ADR-0026.md) 모델 호출별 상한 extract 3.0초·respond 2.0초와 예산 기반 재시도 (점검 F03)
- [ADR-0027](ADR-0027.md) /readyz 응답 전체에 총 마감 하나, 보조 수치는 동시에 읽고 짧은 유예만 (ADR-0011의 /readyz 부분 대체)
