# 한 턴의 Trace 계약

`TurnTrace`는 업무 로그와 분리된 진단·통합 기록의 형식이다. `session_id`, `turn_id`, `contract_version`과 모델·코드·접점의 원본 입출력 및 저장 전후 상태를 포함한다. 각 경계는 해당 계약의 전체 payload 또는 null이다. null은 미확보를 뜻하며 실행 여부·실패 이유는 OrchestratorOutput, LogEntry 등의 확보된 실패 정보와 함께 해석한다.

`LogEntry`는 저장되는 업무 로그 항목이다. 전체 Trace를 업무 로그 안에 강제로 넣거나 저장 DB를 변경하지 않아도 별도로 수집할 수 있다. 어떤 저장 매체에 언제 기록할지는 구현 담당자 영역이다.

이 프로젝트는 고정 Trace 예시가 계약상 유효한지 확인한다. 실제 실행 순서, 모델 정답, payload 수집·복사 성공 여부는 평가하지 않는다. 동일 세션 내 turn_id 유일성, 식별자 생성과 계약 버전별 보관은 수집 담당자와 합의한다.
