# CR-011 LangGraph 버전을 이미지에 기록하는 라벨 추가

- 상태: 확인 요청(작은 건). 공통 규칙은 이미지 라벨 키를 `io.openit.*` 6개로 통일한다(D50). 헤드가 서비스 오케스트레이션을 LangGraph로 바꾸라고 하면서 "이미지 라벨/문서에 버전 기록"을 지시했다.
- 현재 처리: 7번째 키 `io.openit.langgraph`를 survey-service 이미지에만 더하고 값은 설치된 langgraph 버전(예 `1.2.15`)이다. 문서(design 14절, boundary.md)에도 적었다. 다른 영역 이미지에는 영향이 없다.
- 요청: 6개 통일 규칙의 예외로 허용할지, 라벨을 쓰지 않고 문서만 둘지, 키 이름을 바꿀지 정해 달라. deploy의 라벨 검사(`e2e.sh`)는 정해진 키만 보므로 추가 키가 있어도 통과한다.
