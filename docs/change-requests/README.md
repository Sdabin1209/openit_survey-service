# survey-service 변경 요청

헤드에게 넘기는 요청과 정보. "적용 안 함"은 이 영역이 문진 스키마(`schema/`)의 소유자이지만 계약 버전을 올릴 수 있는 변경은 반영 전에 헤드가 알아야 해서(D21) 제안으로만 남긴 것이다.

| ID | 제목 | 상태 | 계약 버전 영향 |
|---|---|---|---|
| CR-001 | 문진 스키마 변경 후보 3건(고정 문장 정보, 도움 요청 사유, pending_id_seed) | 제안, 적용 안 함 | 있음(정수 버전 상승 후보) |
| CR-002 | 골든 예시 보강 요청(문항 세트, 모델 입출력) | 요청 | 없음 |
| CR-003 | 공개 API(O06) 대기 목록 | 정보 | 없음 |
| CR-004 | 컴포넌트 입력의 저장소 조회 범위 확인 | 확인 요청 | 없음(해석) |
| CR-005 | 릴리스의 엔진·런타임 버전이 설치본과 다를 때 정책 | 질문 | 없음 |
| CR-006 | ReleaseManifest의 역할별 serving_config와 I9 load의 단일 serving_config | 확인 요청 | 경계 계약 MAJOR 가능 |
| CR-007 | 세션 ID·턴 ID 형식이 문진 스키마와 경계 계약에서 다름 | 확인 요청 | 선택지에 따라 |
| CR-008 | 골든 예시와 구현 출력의 차이 분류(예시 오류 5건) | 정보 | 없음 |
