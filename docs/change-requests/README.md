# survey-service 변경 요청

헤드에게 넘기는 요청과 정보. "적용 안 함"은 이 영역이 문진 스키마(`schema/`)의 소유자이지만 계약 버전을 올릴 수 있는 변경은 반영 전에 헤드가 알아야 해서(D21) 제안으로만 남긴 것이다.

| ID | 제목 | 상태 | 계약 버전 영향 |
|---|---|---|---|
| CR-001 | 문진 스키마 v2 후보 목록(고정 문장 정보, 도움 요청 사유, pending_id_seed, 조건 규칙의 oneOf 표현) | 보류(적용 안 함, 헤드가 한 번에 올림) | 있음(1→2) |
| CR-002 | 골든 예시 보강 요청(문항 세트, 모델 입출력) | 닫음(원본에 없어 해결 불가) | 없음 |
| CR-003 | 공개 API(O06) 대기 목록 | 일부 해결(D55로 공개 API 구현, 개입 결정 경로는 남음) | 없음 |
| CR-004 | 컴포넌트 입력의 저장소 조회 범위 | 해결(bindings.yaml 대조) | 없음 |
| CR-005 | 릴리스의 엔진·런타임 버전이 설치본과 다를 때 | 결정·반영(MAJOR.MINOR 불일치 거부, PATCH 경고) | 없음 |
| CR-006 | ReleaseManifest의 역할별 serving_config와 I9 load | 해결(model-runtime v0.3.0 반영) | 없음 |
| CR-007 | 세션 ID·턴 ID 형식 차이 | 결정·반영(`x-` 해시 변환) | 없음 |
| CR-009 | 공개 API 문서의 부족한 점과 해석(시작·종료의 turn_id, 상태 코드, 개입 결정 경로 없음) | 확인 요청 | 없음 |
| CR-010 | 추론 서버 규약(model-runtime이 구현할 HTTP 서빙 서버) | 확인 요청 | 없음 |
| CR-011 | LangGraph 버전을 이미지 라벨로 기록(7번째 키 `io.openit.langgraph`) | 승인(D63) | 없음 |
| CR-008 | 골든 예시와 구현 출력의 차이 분류(예시 오류 5건) | 정보(D74로 골든 시험 폐기) | 없음 |
| CR-012 | 직원 알림의 입력원(v2 A 출력에 위험 신호 없음)과 반복 물음 상한 | **미정, 헤드 결정 필요** | 선택지에 따라 |
| CR-013 | 직원 세션 조회 API(`GET /v1/staff/sessions/{id}`)를 PUBLIC_API.md에 추가 | **헤드 반영 요청**(구현 완료) | 없음(스키마 파일 추가만) |
| CR-014 | 결과 조회의 종료 상태 정의와 완료 여부 표시 | 헤드 확인 요청(서비스 동작 변경 없음) | 선택 제안 2는 있음 |
| CR-018 | 영역 경계를 넘는 형식의 스키마 초안 6개(환경 변수·비밀 이름, /readyz, purge 출력, 이미지 라벨, 흐름 표→turn-engine, 문항 세트만 읽는 I4 호출)와 문진 스키마 8개 위치 표 | 초안 제출(헤드 결정 대기) | 계약에 올릴 때 있음 |
| CR-020 | 계약 클라이언트 `HttpModelRuntime.extract`가 `fields`를 넘기게 해 달라 | **헤드 반영 요청**(서비스 쪽 준비 완료) | 계약 패치(2.4.1) |
